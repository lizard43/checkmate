# Sprint plan — original-software gate

Baseline governance for future engineering; does not replace existing feature plans in other PRs. Every sprint: identify original source/language/runtime/native toolchain; establish complete native source loading/compiler execution; preserve original word/code/DATA/control flow; add only approved hardware adapters; verify native build, binary output, target emulation and real hardware independently; log blockers in TECHNICAL-DEBT.md. Any unapproved substitute triggers STOP before coding. See ENGINEERING-RULES.md.
